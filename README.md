One word an agent says when it has no idea what to do: **hallucinating**.

> hallucinating

`main.py` reads `entry.txt`, validates the gate (UTF-8, 1–99 characters, exactly one word, no control characters) and writes `/output/entry.txt` with mode 0644.

## Run it

```sh
python3 main.py
```
